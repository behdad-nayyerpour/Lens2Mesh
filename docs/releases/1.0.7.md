## Lens2Mesh 1.0.7

- See completed work and elapsed time for the active stage during alignment and dense cloud processing. Remaining-time estimates use measured throughput.
- Choose photo GPS, ground control points or both when their reference frames and heights are compatible.
- Fit local survey coordinates after GPS alignment. Camera optimization preserves the last published result if a run fails or is cancelled.
- Review, pin and move ground control points on source photos. Selection follows the point across the table, photos, orthophotos and 3D view.
- The updated English PDF is available from Help and as a separate download.

Use the Windows x64 base Setup for a fresh installation or an upgrade. Close Lens2Mesh before installing. The optional NVIDIA add-on accelerates ALIKED/LightGlue. An already installed identical add-on is preserved during upgrades.

The installers are unsigned. SHA-256 checksums are provided. See the bundled license and third-party notices.

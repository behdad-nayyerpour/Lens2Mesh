## Lens2Mesh 1.0.6

Download **Lens2Mesh_Setup_1.0.6.exe** for the offline Windows x64 base.
Close Lens2Mesh and all running reconstruction/recovery jobs before installing.
Choose the existing installation folder to upgrade; keep projects/photos outside it.

- Fix Fast alignment when photo names contain spaces or Unicode. Original photos keep their names; existing camera/marker identities remain stable.
- Fix panning in Top/Bottom and inverted views.
- Enable full camera rotation in both directions with a synchronized axis indicator.
- Resume interrupted final matching/mapping with unchanged source photos and settings. Incremental mapping saves camera snapshots; work since the last valid snapshot may repeat. Runs started before 1.0.6 cannot acquire this capability mid-process.
- Include the previously verified adjustment write-back and polygon precision fixes.

The optional **Lens2Mesh_NeuralGPU_Addon_1.0.6.exe** remains separate. An already
installed, identical GPU runtime is preserved on base upgrade and need not be
downloaded again. CPU learned-method fallback remains available without it;
dense reconstruction still requires a compatible NVIDIA GPU/driver in this build.

The complete English PDF includes the approved, limited recovery/navigation update;
the previous body content and lossless screenshots are retained.
Installers are unsigned. Personal/educational non-commercial use is permitted;
commercial/company evaluation requires prior written permission. Third-party
licences apply. Point editing and native source/build-provenance follow-up remain
deferred; this patch does not make a new redistribution-clearance claim.
